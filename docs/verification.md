## 已知范围

- 当前标准/高级任务的 `session_event_log` 没有对应事件，主要来源是 App 消息投影与左侧状态监听。工具输入/结果和文本片段可采集，但轮询之间的瞬时投影可能缺失，所有真实尝试标记“部分采集”。
- 后台任务未在左侧虚拟列表中渲染时，DOM 监听可能暂时不可见，持久消息轮询继续补偿。页面重载会重装监听。
- 不读取其他历史会话内容；只查询已确认本平台任务的消息/事件；关联查询仅核对提交附近的输入。事件常见认证字段脱敏。
- App 升级需要重新核验适配，不将版本基线描述为动态能力保证。
- 平台 SQLite 以单运行 JSON 快照事务持久化，适合本地批量测试；大规模长事件运行的写入成本高于规范化事件表。
- 测试成功代表 App 技术终态，不代表业务答案正确或真实账号数据完整。业务工具侧故障可能由模型解释后仍正常完成，按批准口径不做答案质量判定。
